АДМИНКА SUPABASE

1. Откройте Supabase Dashboard именно того проекта, чей URL указан в supabase.js.
2. В SQL Editor выполните supabase-admin-setup.sql и supabase-setup.sql. Эти файлы включают RLS: посетители могут смотреть товары и оформлять заказ, а изменять товары и просматривать заказы может только администратор.
3. В Authentication → Users найдите свой аккаунт. Если он уже есть, используйте его: проверьте подтверждение почты, а при утерянном пароле задайте новый в Supabase. Если аккаунта ещё нет, нажмите Add user → Send invitation, укажите свою почту и примите приглашение из письма. Приглашение подтвердит почту и даст задать пароль.
4. Проверьте в supabase-grant-admin.sql, что указан адрес нового пользователя, и выполните запрос в SQL Editor. Результат должен показать UPDATE 1 и assigned_role = admin.
5. Настройте Authentication → URL Configuration: укажите адрес сайта как Site URL и добавьте адрес сайта с /admin.html в Redirect URLs. Для локального запуска добавьте http://127.0.0.1:8000/admin.html.
6. Откройте /admin.html и войдите с этой почтой и паролем. После назначения роли выйдите из старой сессии и войдите заново.

После обновления каталога повторно выполните supabase-admin-setup.sql: он добавляет размеры, наличие и галерею фото товаров. В админке можно задать эти поля, загрузить главное фото и до 8 дополнительных фотографий. После обновления скрипта заново войдите в админку.

Почту подтверждают один раз при принятии приглашения. Для обычного входа дальше нужны только почта и пароль. Если Supabase сообщает, что email не подтверждён, проверьте письмо-приглашение. Если аккаунту не выдана роль администратора, повторите шаг 4 и проверьте точное совпадение почты.

В интерфейсе админки нет публичной регистрации. Для дополнительной защиты можно выключить самостоятельную регистрацию пользователей в настройках Supabase Auth; существующий аккаунт администратора продолжит входить.

ЛОКАЛЬНЫЙ ПРОСМОТР

Для локального сайта используйте Python 3.10+: в PowerShell выполните py -m http.server 8000, затем откройте http://127.0.0.1:8000. Браузерные библиотеки находятся в assets/vendor и не требуют доступа к CDN. Каталог, вход администратора и облачные заказы работают через Supabase и требуют настройки проекта по инструкции выше.

Каталог и фотографии в проекте демонстрационные. Перед публикацией загрузите реальные фотографии и проверьте названия, цены, материалы, цвета и наличие в админке. Сроки, стоимость и географию доставки, а также способы оплаты указывайте только после их подтверждения.

WHATSAPP_ORDER_NUMBER в supabase.js настроен как публичный контакт магазина в международном формате. Номер виден в исходном коде и ссылке — не используйте личный номер, если не хотите показывать его покупателям. Универсальная ссылка WhatsApp открывает приложение на телефоне или WhatsApp Web на компьютере; клиент проверяет готовое сообщение и отправляет его вручную. Заказ сохраняется в Supabase до перехода в WhatsApp.
